# 贴纸拼拼乐 · 素材与制作设计资料

本文件夹为当前游戏的美术、音频、业务设计及制作步骤资料，不含程序源码、开发模板或测试脚本。

## 如何放到桌面
下载同名ZIP压缩包，将其解压到你电脑的桌面，即可得到“贴纸拼拼乐_素材与制作设计资料”文件夹。该资料包不是在线试玩地址，也不包含可直接双击运行的游戏。

## 文件内容
- 01_玩法与设计：最新玩法说明、关卡与教学配表、装备纸质与成就奖励、自由手账说明。
- 02_制作流程：设计步骤、视觉制作方法、修订记录和验收结论。
- 03_图片素材：37张主线及公共界面素材；另列4张暂缓线索素材，不能视为线索玩法验收完成。
- 04_声音素材：15路本地制作音频；已发布版本另提供地址清单，如成功下载则附播放版本。
- 05_效果与验收截图：当前目录、关卡、装备、收藏、手账及手机效果。旧便签输入截图用作交互展示，文件名已标明。
- 06_清单：素材用途、文件信息、资料包校验说明。

## 当前业务范围
12个主关、7个教学奖励关、6类主题、4把镊子、5种纸质、20项成就。自由手账含两页、食材/成品/便签/背景；便签最多20字，颜色轮盘自定义背景，可保存并导出PNG。

线索小铺按用户要求暂停，入口隐藏。未采用的芥末、芝麻及手卷海苔错误初稿不导出；暂缓的4张食材图单独归类，不与已验收主线素材混淆。

## 使用与限制
保留现有本地保存和奖励规则。本地手账不跨设备同步，清理浏览器站点数据会清除手账。浏览器与模拟触摸验证不等同于真机和人工听觉验收。

素材属于本项目制作成果。资料包不附第三方参考作品的图片、代码或音频，也不对第三方商标或商业使用权作额外保证。
