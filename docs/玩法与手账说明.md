# 玩法与手账说明

## 核心体验
玩家从左侧贴纸页揭起食材，在右侧料理轮廓逐层拼贴，完成后获得积分、收藏和成就。画面主题为午后木桌、暖色纸册与料理贴纸。

## 主线规则
- 原图案层次先下后上；同层贴纸不限制左右先后。天妇罗每张面团依赖其对应虾仁，虾仁之间与面团之间均可自由先后。
- 撕起一批与贴放一批各算1步；单镊子一次1张，双镊子可选择1～2张，跨作品合理配对以节省步数。
- 双批放置是一次整体判断，食材、所属作品、层次任一错误都不部分贴入；错误批次保留在手中。
- 多作品“撤回重选”只作用于当前未提交批次或预选择；返回本次揭起前位置与步数，不撤销已提交历史。
- 来源与目标显示宽高相同，左页材料按原尺寸固定分页；翻页不消耗步数，跨页选择不丢失。
- 限步关需在预算内完成整桌；完成的作品仍显示。重置保留既有收藏和已消费加映券。
- 加映券手动消费1张，当前主关成功额外100分；失败、整关重玩或退出不返还。

## 成长
教学首次奖励共920分；主关原色纸理想通关共3000分。20项成就奖励共3230分，达到条件后手动领取一次。购买花费不降低累计获得积分；稀有工具和纸质由成就解锁，不自动装备。收藏为6主题×5纸质共30组合。

## 自定义手账
- 首页底栏入口，最右仍为“返回大世界”；线索小铺隐藏。
- 托盘：接触过的食材、已收藏成品、便签、背景。食材无限使用，不扣积分。
- 两页，每页最多40张；点阵/横线两纸型与背景颜色独立选择。
- 便签最多20个可见字符，支持中文与表情、超长粘贴截断、取消与保存。贴入后选中可重新编辑，多张文字分别保存。
- 背景色盘可点选/拖动色相与饱和度，有调亮/调暗及5个柔和快捷色。两页颜色分别保存。
- 贴纸可旋转、缩放、前后层级、翻面、移除，支持撤销重做。放大旋转后的整体框仍限定纸面。携带途中退出或翻页恢复原项。
- 手账海苔默认与左侧示例82×54设计尺寸一致；不改变主线成品中的海苔。
- 自动保存在本地，导出900×560本页PNG包含所选颜色与便签文字。

## 画面与输入
桌面横向1280×720，整体等比适配手机；推荐横向拼贴。顶部积分、声音、暂停在安全边距内，左页标题与券/撤回分行；三件作品名称与进度上下居中。单作品牛肉面组合底部到设计y488，离书页装订边留空。
