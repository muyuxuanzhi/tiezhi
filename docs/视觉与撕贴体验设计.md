# 视觉与撕贴体验设计

## 视觉方向
暖色日式料理贴纸手账。使用手绘水粉与彩铅细节，乳白模切贴纸边、轻微纸厚和接触阴影；料理从顶视到浅俯视，清晰可辨，不用照片或表情符号替代食材。主色为蜂蜜木桌、象牙纸面、珊瑚红、抹茶绿和淡青。

## 图片用途
木桌承托全页面，展开册形成左右页，封面用于首页。料理按米饭、鱼片、海苔、虾仁、面团、汤碗、面条等独立透明食材拼成，不用一张完整成品图替代逐层交互。客厅同样以地毯、沙发、圆木桌、落地灯、靠垫、绿植分层。镊子与纸质材质重复用于装备与实际操作。

## 五段手感
1. **轻翘**：边缘悬停约120毫秒，离开时收回；触屏按下即时反馈，不增加等待门槛。
2. **卷曲**：6设计像素内不推进；随着滑动露近白纸背与折痕明暗。短拖松手约160毫秒回弹，不扣步。
3. **揭离与持有**：约120毫秒展开悬浮，暂时1.05倍；跟手轻微平滑及±14度轻摆，柔投影；触摸持有图上移避开手指。
4. **对位**：只有食材、作品和层次都允许的目标才辅助吸附；进入/离开范围带迟滞，避免边缘抖动，不显示隐藏答案。
5. **贴下**：对齐约80毫秒、展开约220毫秒、轻按约90毫秒，双批第二张稍后启动，规则一次整体提交。

磨损只反馈重复揭起，完成后抚平；收藏保持干净外观。不使用设备物理振动。

## 声音职责
背景音乐营造午后小食堂。揭起、对位、错误、完成、结算和兑换分别反馈状态。4种材质摩擦随移动速度调整，停手、揭离、取消、静音与暂停立即停止；3种轻按压轮换减少重复。音频状态通过验证，不宣称与参考视频原声一致。

## 排版原则
文字和基本操作不各生成一张图。标题、计数、券/撤回分组；顶部与底部保留浅纸条提高对比。料理组合按整体居中，不贴书页装订边，左右来源与目标同尺寸。自由手账便签与背景为独立创作，不影响主线玩法。
